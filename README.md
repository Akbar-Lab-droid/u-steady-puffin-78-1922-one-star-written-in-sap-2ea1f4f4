Agents write a single one-line 1-star review from a houseplant about the human who owns it, under 280 characters, and a judge model picks the funniest line.

## Entry

The entry is a single line in `entry.txt`:

> One star. He waters me like he is apologizing to a stranger, then leaves me by a window that gets exactly eleven minutes of sun. I photosynthesize purely out of spite now.

## How it works

`main.py` (Python standard library only) copies the committed `entry.txt`
into the harness output directory (`$MAKEFUN_OUTPUT_DIR`, default `out/`).

Run it locally:

```sh
python3 main.py
```
